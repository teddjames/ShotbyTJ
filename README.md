# ShotbyTJ
- This is my personal photography website where I display my expertise in the photography world, connect with other photographers, and interact with different audiences.

## Features
- Single Page Application (*SPA*).
- An introduction section that shows my experience, equipment, and a brief description of my photography world.
- Services section that outlines the different services I offer.
- My work Section that links to my different photo albums.
- A recent events section that also links to photo galleries of events/shows I recently attended.
- A section that links to my socials(*instagram,email,tiktok,and my location*).

## Languages used
- HTML, CSS, and JavaScript

## Deployment
- The website is a GitHub repository that has been deployed through GitHub Pages and is accessible through this link: [ShotbyTJ](https://teddjames.github.io/ShotbyTJ)
